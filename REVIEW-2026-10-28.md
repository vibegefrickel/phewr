## Batch A: bugs

Order: crash first, then state that goes stale, then processes.

Items 1, 3, 4, 5, 7, 8 and 9 are merged in `c40a1a6` (worker `fix-review-a`, 2026-10-30). Items 2
and 6 are in `9d84897` (`k2-native-loops`). Item 20 is in `6aaae8a`. Items 10 to 18 are merged in
`a3c493c` (worker `fix-review-b`, 2026-10-30, automatic review): the scan error behaves like a
status note, the prefetch bug of item 11 was not reachable (a guard stays), the 12-bit download
stays `nv12`. Item 19 (`Esc` quits the grid) is a decision of the maintainer. Open after the
merge: the prune does not remove a stale `.partial` cube file or a `state.toml.<pid>.tmp` file.

1. **confirmed** `src/app/grid_loops.rs:152` panics on a loop with zero frames. `id_at`
   computes `self.ids.len() - 1`. The cache reader `decode_loop_file`
   (`src/app/disk_cache.rs:187-206`) accepts `count` 0 and 1, and `poll_grid_loops`
   (`grid_loops.rs:405`) inserts the result without a count check. The decoder path rejects
   fewer than 2 frames (`src/grid_loop.rs:124`). A cut `.loop` file crashes the TUI at the first
   tick. Fix: reject `count < 2` in `decode_loop_file`. Add a test with `count = 0`.
2. **confirmed** `src/kitty_output.rs:55-73` and `82-108`: the first video frame can leave a
   synchronized update open. `render_video_frame` queues `BeginSynchronizedUpdate` and the
   placement clear, then `render_video_frame_to` returns early when `cells.width == 0` (a 1-row
   terminal) without `EndSynchronizedUpdate`. Fix: pass `clear` into `render_video_frame_to`
   and queue the clear after its own `Begin`. Feed the wrapper to `FakeTerminal` in a test and
   assert `synchronized_depth == 0`.
3. **confirmed** `src/app/zoom.rs:131-142`: a failed full-resolution decode is silent and
   repeats. On `Err`, `poll_source` clears `source_target` and sets no `error`. Each later
   `load_if_needed` (`src/app/fullscreen.rs:203`) starts the decode again. Fix: remember the
   failed index, set `error`, and add a test for `poll_source` with an `Err`.
4. **confirmed** `src/app/fullscreen.rs:79-84` `enter_gallery` and `src/app/directory.rs:13`
   `switch_to_dir` drop `loaded` but keep `source`, the full-resolution image of the last zoom
   (about 100 MB for 24 MP). Only `reset_zoom_state` frees it. Fix: call `reset_zoom_state` in
   both.
5. **confirmed** `src/main.rs` has no panic hook. The default hook prints to stderr while the
   alternate screen is on, and `restore` then discards the text. The user sees an empty prompt.
   Fix: `std::panic::set_hook` that calls `disable_raw_mode` and `LeaveAlternateScreen` before
   the default hook.
6. **confirmed** `src/app/grid_loops.rs:488` and `src/app/thumbnails.rs:134`: the loop jobs run
   on detached threads and nothing cancels them on quit. `forget_grid_loops` runs only on a
   thumbnail invalidation. A quit during the loop decode of a long clip leaves an ffmpeg
   (`-skip_frame nokey`) until its next write hits EPIPE. Fix: `impl Drop for GridLoops` that
   calls `cancel_jobs`, or a cancel in the quit path of `run`.
7. `src/player/mod.rs:247-253`: a player run has no deadline for its first frame. If ffmpeg
   starts but writes nothing, the view stays in "playing" with no frame. The first-frame
   thumbnail and the probe have a timeout. Fix: a deadline in `start_run` and in the restart of
   `catch_up`. Add a `FakeDecoder` test for a run without a frame.
8. **confirmed** `src/keys/mod.rs:111` passes `key.code` only, and `src/keys/gallery.rs:24-27`
   pushes every `Char(c)`. Ctrl+C, Ctrl+U or Ctrl+W during a search insert `c`, `u` or `w`.
   Fix: pass the `KeyEvent` and skip presses with `CONTROL` or `ALT`. Add a test.
9. **confirmed** `src/app/disk_cache.rs:226` and `257`: the first write prunes twice.
   `CACHE_PRUNED.get_or_init` prunes, then `sequence == 0` satisfies `is_multiple_of(64)`. Each
   prune walks the whole cache directory on a decode thread. Fix: prune on `sequence % 64 == 63`,
   or skip `sequence == 0`.
10. `src/app/scan.rs:18-22`: a scan error and a decode error share `self.error`. A permission
    error of the scan hides the video placeholder (`shows_video_placeholder` tests
    `error.is_none()`), and `enter_fullscreen_at` clears the scan error. Fix: a separate
    `scan_error`, or the status note of `LoopState`.
11. `src/app/folder_prefetch.rs:111-116`: `cancel` overwrites a `stopping` handle that still
    runs. Two cancelled threads can decode at once. Fix: join or keep a `Vec` of stopping handles.
12. `src/run_loop.rs:190` and `206-236`: `pending_emits` grows in every mode and clears only in
    `finish_render` of the grid. A late thumbnail while the user rests on a fullscreen photo keeps
    the 10 ms poll until the next step. Fix: clear or skip the emits outside `ViewMode::Gallery`.
13. `src/config.rs:308-313` and `268-284`: a parse error of the state file gives
    `StateFile::default()`, and the next `+` writes that default back. One bad line erases 200
    folder entries. Fix: keep the old file on a parse error, and write through a temp file and a
    rename.
14. `src/scanner.rs:122` skips hidden folders, `148-183` keeps hidden files. AppleDouble files
    (`._IMG_0001.jpg`) on a USB stick show as broken cells. Fix: apply the same rule to files.
    Add a test.
15. `src/player/probe.rs:371`: `pix_fmt.contains("10") || pix_fmt.contains("12")` marks
    `yuv410p` as 10 bit and maps 12-bit formats to `p010le`. The GPU chain then fails and the
    software fallback pays one extra ffmpeg start. Fix: match the bit depth suffix. Add parse
    tests for a 12-bit `pix_fmt` and for `smpte2084`.
16. `src/app/delete.rs:137-138`: `self.images.len() - removed.len()` has no guard. Use
    `saturating_sub`. The delete code goes away later, so keep this to one line.
17. `src/player/tone_map.rs:460-466`: a failed `fs::write` or `rename` leaves a `.partial` cube
    file. Make sure that the cache prune removes that name, or remove it on the error path.
18. `src/run_loop.rs:88`: every `Event::Key` clears the status note, also a key release under
    the Kitty keyboard protocol. Fix: clear on `KeyEventKind::Press` only.
19. `src/keys/gallery.rs:37`: `Esc` quits from the grid. `Esc` also closes the help, the delete
    question and the search, and crossterm delivers an unparsed sequence as a bare `Esc`. Decide:
    keep it, or let only `q` quit.
20. **confirmed, fixed in main on 2026-10-30 (uncommitted)** `src/run_loop.rs` `render_images`:
    the help popup deleted the pictures on open, but a thumbnail that arrived while the popup
    was open went out through `emit_new_thumbnails` and showed above the popup (seen in
    herdr). The fix holds every Kitty write of every view while `help_visible` is true and
    drops the pending emits, because the key that closes the popup renders the view again.
    Test: `the_help_popup_holds_the_late_thumbnails_of_the_grid`. The help popup is the only
    overlay that covers pictures. The info panel is a split, and the delete question, the
    search line and the notes live in the status row.
